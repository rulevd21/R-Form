# R/Form Operating System v1.1.5

Date: 2026-08-28

## Runtime finding

v1.1.4 still emitted standalone `svg` tokens and the forced rich-output surface made the symptom worse.

## Architectural change

Do not render the full canonical Telegram post inside ChatGPT for `TEXT_ONLY + Visual_Status=NOT_REQUIRED`.

`Подготовь публикацию` now:
- verifies canonical `Telegram_Text`;
- verifies state and QA;
- returns exact Content_ID / statuses / preview-review state;
- returns canonical Text_URL / Work_Packet_URL when available;
- returns one owner action;
- routes the actual final preview to existing Channel Control / Owner Bot.

`Покажи предпросмотр` routes to the canonical preview surface instead of fabricating a second ChatGPT preview.

## Why

The publication artifact already exists in R/Form. ChatGPT is the orchestrator; Channel Control / Owner Bot is the exact Telegram preview and approval surface.

## Scope

Skill only. No Channel Control, Owner Bot, Telegram Autopost, scheduler, datastore, approval-state, or external-publication code changed.
