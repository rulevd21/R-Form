# R/Form Operating System v1.1.7

Hotfix for Strength Trend Scout runtime determinism.

## Fixed

- packaged the canonical `scripts/strength_trend_scout_v1.py` inside the installable Skill;
- made deterministic scorer execution authoritative for score/class/disposition;
- added fail-closed `SCORER_UNAVAILABLE` behavior when the script cannot run;
- made `WATCH → CONTENT_CANDIDATE` explicitly invalid;
- added a regression fixture reproducing the observed one-platform `64.54` WATCH case;
- CI now verifies the scorer is present in the installable ZIP.

## Unchanged

- R/Form OS remains the sole command router;
- Agent Reach remains an optional subordinate acquisition layer;
- external evidence remains read-only;
- `CONTENT_QUEUE`, Owner Bot and Telegram Autopost boundaries are unchanged;
- no production datastore, Apps Script deployment, credential or Telegram transport change is included.
