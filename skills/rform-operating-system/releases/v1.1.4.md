# R/Form Operating System v1.1.4

Date: 2026-08-28

## Runtime defect addressed
v1.1.3 still emitted an orphan `svg` token before a TEXT_ONLY Telegram preview.

## Root cause
The previous patch focused on sanitation, but the output surface itself was not constrained strongly enough.

## Change
- TEXT_ONLY full post uses `social_post` writing block when supported;
- plain prose fallback only;
- code/SVG/artifact/image render surfaces forbidden;
- renderer leak is a hard PREVIEW QA failure;
- CP18–CP19 added.

## Scope
Skill only. No Channel Control, Owner Bot, Telegram Autopost, scheduler, datastore, approval state, or external publication changes.
